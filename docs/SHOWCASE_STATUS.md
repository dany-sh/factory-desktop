# Showcase Status

Factory Desktop is an inactive, archived portfolio project. Development was parked on September 12, 2026, and the repository is retained to demonstrate the design and implementation of a review-first, local macOS orchestration prototype.

## Final verified state

- The default branch retains the complete project history from the initial scaffold onward.
- All project commits use the repository owner's GitHub noreply author address.
- `swift test` passes 196 tests in the final pre-archive checkout.
- Runtime databases, prompts, run logs, snapshots, and generated worktrees are not part of the public repository.
- No autonomous editing, production deployment, or live service is represented by this showcase.

## Scope boundary

The shipped source implements Factory Desktop: a local coding-project, task, worktree, and runner orchestration prototype. Documents under `docs/architecture`, `docs/product`, and `docs/roadmap` also preserve a later legal-workspace product exploration. Those documents are design artifacts; they do not mean the proposed legal capabilities were implemented.

## Maintenance policy

This repository is parked and may be archived on GitHub. No roadmap, support, security-update, or compatibility commitment is implied. Forks and reuse should independently assess the code, its dependencies, and the third-party TinyMCE assets and notices included in the source tree.
